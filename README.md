## Supported models

Jjama currently supports non-MoE Llama3-style models, in FP32, FP16, and BF16 precision. Including:

- [Llama3](https://ai.meta.com/blog/meta-llama-3/)
- [Qwen2](https://qwenlm.github.io/blog/qwen2/) & [Qwen3](https://qwenlm.github.io/blog/qwen3/)
- [Monad](https://huggingface.co/PleIAs/Monad) & [Baguettotron](https://huggingface.co/PleIAs/Baguettotron)
- [SmolLM](https://huggingface.co/collections/HuggingFaceTB/smollm) & [SmolLM2](https://huggingface.co/collections/HuggingFaceTB/smollm2)
